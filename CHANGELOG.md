# История изменений

## 1.0.0

- Первый публичный выпуск.
- MP3/MP4, потоковое воспроизведение, перемотка, повтор.
- Плейлист из папки и отдельно добавленные треки.
- Приблизительный поиск по буквам и опечаткам, вставка из буфера обмена.
- История прослушиваний текущего сеанса.
- Тёмная тема, системный акцент и ручная палитра с градиентами.
- Сохранение плейлиста, позиции, громкости, Mute и повтора.
- Установщик для Windows с ярлыками, деинсталлятором и автозапуском.
